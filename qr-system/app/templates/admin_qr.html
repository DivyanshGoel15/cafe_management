💡
Permanent QR Architecture: Each table has a fixed, permanent URL (e.g. /table/table_7). The QR sticker never changes even if menu items, categories, descriptions, or prices are modified. The backend serves the real-time menu dynamically upon scan.

👥 Multi-Customer Table Session Aggregation

Multiple customers seated at the same physical table scan the same permanent QR code. Each customer orders and pays independently for their selected dishes. The system aggregates all confirmed orders into the unified Table Dine-In Session total while preserving each individual customer's identity and receipt.
